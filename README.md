 Python Exception Handling

This is a small Python practice project that I made while learning exception handling.

In this project, I used try and except to handle invalid age input. If the user enters a number, the program shows the age. If the user enters letters, it shows an error message instead of stopping the program.

What I Practiced

- try and except
- ValueError
- while loop
- break
- Taking input from the user

Example

If the user enters:
abc

The program shows:
Please enter correct number

If the user enters:
19

The program shows:
Your age is: 19

This project helped me understand how to handle errors and make a Python program more user-friendly.
